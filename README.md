# Plain HTML Upload UI

This is a simple, static web application that provides a minimal and clean user interface for uploading text files (`sample_program.txt`).

## Features
- **Plain HTML and CSS**: No JavaScript or complex build tools.
- **Minimalist UI**: Clean, responsive, and modern look.
- **Upload Form**: A form specifically tailored for uploading `.txt` files.

## Running Locally

Because this project is purely static, you can run it using any basic HTTP server. For example, using Python 3:

```bash
python3 -m http.server 3000
```

Then visit `http://localhost:3000` in your browser.
